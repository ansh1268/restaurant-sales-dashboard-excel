# Restaurant Sales Dashboard

## Project Overview
This is a beginner-level Data Analytics project built in Microsoft Excel.

The dashboard provides insights into restaurant sales performance, customer ratings, food preferences, and location-wise sales trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Map Chart
- Data Cleaning

## Key Metrics
- Total Sales
- Total Orders
- Average Rating
- Average Order Value (AOV)

## Dashboard Features
- Monthly Sales Trend
- Daily Sales Trend
- Food Type Analysis (Veg vs Non Veg)
- State-wise Sales Analysis
- Top Selling Dishes
- Quarterly Performance Analysis

## Skills Demonstrated
- Data Cleaning
- Data Analysis
- Dashboard Design
- Business Insights
- Data Visualization
